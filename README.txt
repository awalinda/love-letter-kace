# A Little Letter For You ♡

## Folder structure
- index.html
- style.css
- script.js
- assets/
  - background.jpeg (your 4th photo; lightly blurred through CSS)
  - photo-3.jpeg (welcome page photo)
  - photo-1.jpeg and photo-2.jpeg (small polaroid frames on the letter page)

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (or use an existing one).
2. Upload `index.html`, `style.css`, `script.js`, and the whole `assets` folder.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Open the published Pages URL after deployment finishes.

Keep the folder and file names unchanged so the image paths continue to work.
